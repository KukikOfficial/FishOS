# FishOS roadmap

Ordered by user value; each step should keep `make test` green.

1. Editor undo/redo and find; preserve tabs.
2. Terminal mouse selection and copy; pipes between commands (`a | b`).
3. Image viewer and a settings app (wallpaper colour, keyboard layout).
4. Notifications from the desktop (e.g. "disk full") instead of per-app dialogs.
5. Split the desktop into compositor and shell processes.
6. Application SDK: install headers + `libfishos.a`, document the window protocol for third parties.
7. Shared libraries once Fihcore supports them.
