# FishOS 🐟

Полноценная 32-битная графическая операционная система на C++ и Ассемблере для архитектуры x86 (IA-32).

---

## 🚀 Что реализовано в архитектуре

### 1. Низкоуровневое ядро и прерывания (Core Kernel & Hardware)
- **GDT & TSS**: Таблица дескрипторов сегментов ядра (Ring 0) и пользователя (Ring 3), а также Task State Segment (TSS) для безопасного переключения стека ядра при прерываниях.
- **IDT & PIC (8259A)**: Таблица прерываний на 256 шлюзов, переназначение контроллера PIC.
- **Обработка исключений CPU и BSoD**: Векторы 0–31 (Деление на ноль, General Protection Fault, Page Fault и т.д.) перехватываются графическим «Синим экраном смерти» с полным дампом регистров (EIP, ESP, EAX, EBX, CR2).
- **Системный таймер PIT (8253/8254)**: Таймер IRQ0 настроен на 100 Гц (10 мс на тик), точный отсчет времени и `sleep_ms()`.
- **Аппаратные прерывания PS/2**: Клавиатура (IRQ1) и мышь (IRQ12) работают через аппаратные прерывания.

### 2. Управление памятью (Memory Management)
- **Физический аллокатор страниц (PMM)**: Битовая карта (bitmap) страниц по 4 Кб на основе карты памяти Multiboot.
- **Куча ядра (Kernel Heap)**: Двусвязный блочный аллокатор (`kmalloc`, `kfree`, `kcalloc`, `krealloc`).
- **Перегрузка C++ `operator new` / `delete`**: Поддержка создания объектов в динамической памяти ядра.

### 3. Многозадачность и системные вызовы (Multitasking & Syscalls)
- **Планировщик задач (Scheduler)**: Вытесняющая и кооперативная многозадачность (Round-Robin), переключение контекста процессора в ассемблере (`context_switch`).
- **Системные вызовы (`int 0x80`)**:
  - `SYS_YIELD` (0), `SYS_EXIT` (1), `SYS_SLEEP` (2), `SYS_GETPID` (3), `SYS_GETUPTIME` (4), `SYS_VFS_READ` (5), `SYS_VFS_WRITE` (6), `SYS_BEEP` (7).
- **Пользовательский режим (Ring 3 User Mode)**: Возможность запуска изолированных пользовательских задач (`enter_user_mode`) с общением через сисколлы.

### 4. Иерархическая файловая система (Hierarchical VFS)
- Поддержка произвольной вложенности директорий (`/docs`, `/system`) и путей.
- Файлы произвольного размера на базе динамической кучи `kmalloc`.
- Разбор TAR-архива Initrd с автоматическим созданием директорий и файлов.
- Персистентность на виртуальный жесткий диск IDE ATA PIO.

### 5. Графическая оконная среда (GUI Desktop)
- Разрешение 1024×768, 32 bpp (TrueColor VBE), двойная буферизация.
- Оконный менеджер: перемещение окон, Z-order, сворачивание, разворачивание, панель задач, часы RTC, меню «Пуск».
- **4 встроенных приложения**:
  1. **File Explorer**: Навигация по каталогам (`..`, `[DIR]`), создание папок, файлов и удаление.
  2. **Text Editor (Notepad)**: Текстовый редактор с кареткой, миганием курсора и сохранением в VFS.
  3. **LitePaint Studio**: 6-цветная палитра, рисование и очистка холста.
  4. **System & Tasks Monitor**: Мониторинг аптайма, физической памяти (RAM), списка процессов ядра и кнопка создания фонового Ring 3 процесса с системными вызовами!

## 🛠️ Сборка и запуск

### Требования (macOS / Homebrew):
```bash
brew install i686-elf-gcc i686-elf-binutils i686-elf-grub xorriso qemu
```

### Сборка ISO:
```bash
make clean
make all
```

### Запуск в QEMU:
```bash
make run
```
*Команда автоматически создаст образ виртуального диска `hdd.img` (10 Мб) и подключит эмуляцию звука PC Speaker через аудиодрайвер macOS CoreAudio.*
